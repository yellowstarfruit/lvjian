律简｜大学生校园权益智能咨询助手

一句话定位
基于 RAG（检索增强生成）技术，专为大学生打造的校园维权 AI 工具，不止是聊天，更是从咨询到产出的闭环助手。

核心痛点
通用大模型（如 ChatGPT）在回答校园维权问题时，容易“编造”法律条款，且不了解具体学校的校规。大学生维权面临“信息差大、门槛高”的困境。

功能亮点（三大闭环）

·专属知识库问答：喂入学校红头文件，严格限定 AI 回答范围，回答附带原文出处，杜绝“法盲 AI”。
·合同智能体检：上传实习合同/学校通知 PDF，AI 自动扫描并结构化输出“高/中/低”风险条款。
·一键文书生成：输入简单情况，自动生成正式申诉书/协商函，支持一键下载 .docx Word 文档。

技术护城河

· 架构：Streamlit + 通义千问（Qwen-Turbo）+ ChromaDB 向量数据库
· 防幻觉：RAG 检索增强生成 + 多轮对话记忆
· 全云端：部署于 Streamlit Cloud，公网可直接访问，手机完美适配
